# Rahim Store 3D — https://zakriyaamir.github.io/rahim-store-3d/

## v3 — full catalog + multiplayer
- All 7,506 rahimstore.com products (every size/variant separate), 164 categories in 13 departments, 61 double-sided shelf units, hanging dept signs, end-cap category lists, per-category shelf tags, searchable list (F), full map (M).
- Products rendered via instanced meshes + lazily loaded 2048px webp atlases.
- Multiplayer: Supabase Realtime broadcast + presence (no tables), rooms of max 10 (overflow to next room), avatars with carts/name tags, add-to-cart toasts. `?solo` = offline.
